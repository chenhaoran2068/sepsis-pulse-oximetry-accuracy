# Tested software environment

The synthetic demonstration and the integrated MIMIC-shaped standardized-input chain were checked on Windows with R 4.5.1 (ucrt) and Python 3. The observed R packages and versions included: `data.table` 1.17.8, `igraph` 2.2.1, `digest` 0.6.39, `lubridate` 1.9.4, `stringr` 1.6.0, `lme4` 1.1-37, `Matrix` 1.7-3, `nlme` 3.1-168, `ranger` 0.17.0, `fastshap` 0.1.1, `mice` 3.18.0, `miceadds` 3.20.10, `car` 3.1-3, `sandwich` 3.1-1, and `posterior` 1.6.1. The exact installed versions of an individual run are written to its `r_package_versions.tsv` receipt. These are observed versions, not a tested compatibility range.

The two Python entrypoints install missing packages into fresh, Git-ignored per-run R libraries. An existing isolated library can be supplied to the integrated entrypoint with `--extra-r-library`. The repository does not include a lockfile, and no non-Windows system has yet passed a clean run. Both entrypoints accept `--rscript PATH` when Rscript is not on `PATH`. No local library, Python environment, or clinical data are bundled.
